L5-S1 Motion Pro — SITE 7.0

1. Descompacte este ZIP.
2. Envie todos os arquivos e pastas extraídos para a raiz do repositório.
   O index.html precisa estar na raiz, e não dentro do ZIP.
3. GitHub: Settings > Pages > Deploy from a branch > main > /(root) > Save.
4. Abra o endereço publicado pelo GitHub.

Atualização: substitua os arquivos antigos e retire as demonstrações anteriores
antes de enviar os novos materiais. Exporte o backup do app antes de mudar o
endereço de publicação, limpar os dados ou trocar de aparelho.

O projeto Android Studio é outro pacote, utilizado para gerar APK.
Leia README.md para instruções de uso e detalhes desta versão.
