# L5-S1 Motion Pro — web V8

Diário com rotina semanal/manhã/noite, plantões e descanso, metas por exercício, sessão por séries, histórico, respostas e relatório semanal. Os materiais da V7 foram preservados.

Publique o conteúdo completo desta pasta em HTTPS, incluindo `planner-core.js` e `enhancements.js`. Para testar: `python3 -m http.server 8080` e abra http://localhost:8080. Não abra por file:// no navegador.

Em Ajustes > Gemini, cole a chave, escolha `gemini-3.5-flash-lite` ou outro ID disponível, salve e teste. Só as consultas solicitadas são enviadas ao Google; registros precisam ser selecionados antes de enviar. A chave não entra no backup. Sem marcar Lembrar, a chave fica apenas na aba.

O diário e as mídias funcionam offline após o primeiro carregamento completo. Gemini requer internet. Lembretes no site só aparecem com a página aberta; notificações com Iniciar/Adiar são recursos do APK.

O backup automático requer navegador com acesso a pasta, autorização e página aberta. Caso não seja suportado, use Exportar/Importar backup. Importar substitui os dados atuais: guarde uma cópia antes se necessário.

Para atualizar, substitua todos os arquivos web. O cache V8 substitui os caches anteriores. Mantenha o endereço/origem para preservar o armazenamento local. APK e site têm dados separados; a transferência é por backup JSON, sem sincronização em nuvem.

A IA explica textos e registros; não acompanha câmera, não diagnostica nem muda automaticamente as metas. Siga a orientação do profissional que acompanha seus exercícios.
